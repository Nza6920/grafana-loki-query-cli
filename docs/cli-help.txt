$ loki-query --help
usage: loki-query [-h] [--version] [--config CONFIG]
                  {query,trace,export,resume,profiles,config} ...

Query Loki logs and metrics through a Grafana datasource proxy.

positional arguments:
  {query,trace,export,resume,profiles,config}
    query               Run a Loki query_range request.
    trace               Query exact trace IDs and show a timeline.
    export              Export a saved scan without configuration,
                        credentials, or HTTP.
    resume              Continue only unresolved saved scan intervals.
    profiles            Inspect configured profiles.
    config              Inspect and validate configuration.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --config CONFIG       Configuration file (default: environment or platform
                        config path).

$ loki-query query --help
usage: loki-query query [-h] --profile PROFILE [--query-type {log,metric}]
                        [--since SINCE | --start START] [--end END]
                        [--limit LIMIT] [--direction {backward,forward}]
                        [--step STEP] [--output {human,raw,jsonl}]
                        [--timeout TIMEOUT] [--scan]
                        [--max-http-attempts MAX_HTTP_ATTEMPTS]
                        [--max-elapsed-seconds MAX_ELAPSED_SECONDS]
                        [--max-records MAX_RECORDS] [--work-dir WORK_DIR]
                        [--report REPORT]
                        logql

positional arguments:
  logql                 Complete LogQL query, or - to read stdin.

options:
  -h, --help            show this help message and exit
  --profile PROFILE     Named target profile.
  --query-type {log,metric}
                        Declared query result type (default: log).
  --since SINCE         Relative duration such as 15m or 2h.
  --start START         RFC 3339 range start.
  --end END             RFC 3339 range end (default: now).
  --limit LIMIT         Maximum entries per request (1-5000; default: 100,
                        scan: 1000).
  --direction {backward,forward}
                        Log result direction (default: backward).
  --step STEP           Metric query step in Loki seconds or duration form.
  --output {human,raw,jsonl}
                        Output format (default: human).
  --timeout TIMEOUT     HTTP timeout in seconds (default: 30).
  --scan                Adaptively scan dense or timed-out intervals with
                        bounded execution.
  --max-http-attempts MAX_HTTP_ATTEMPTS
                        HTTP attempt ceiling including retries (scan default:
                        60); explicit cap emits stderr accounting.
  --max-elapsed-seconds MAX_ELAPSED_SECONDS
                        Scan elapsed budget (default: 300).
  --max-records MAX_RECORDS
                        Scan retained record budget (default: 10000).
  --work-dir WORK_DIR   Persist scan progress and evidence in this explicit
                        directory.
  --report REPORT       Write log completeness JSON to this file.

$ loki-query trace --help
usage: loki-query trace [-h] --profile PROFILE --selector SELECTOR
                        [--source {json,label}]
                        (--since SINCE | --start START) [--end END]
                        [--limit LIMIT] [--direction {backward,forward}]
                        [--output {human,raw,jsonl}]
                        [--service-field SERVICE_FIELD] [--field NAME]
                        [--path POINTER] [--timeout TIMEOUT]
                        [--max-http-attempts MAX_HTTP_ATTEMPTS] [--scan]
                        [--max-elapsed-seconds MAX_ELAPSED_SECONDS]
                        [--max-records MAX_RECORDS] [--work-dir WORK_DIR]
                        [--report REPORT]
                        trace_id

positional arguments:
  trace_id              Complete case-sensitive trace ID.

options:
  -h, --help            show this help message and exit
  --profile PROFILE     Named target profile.
  --selector SELECTOR   One Loki stream selector; no pipeline.
  --source {json,label}
                        Trace field source (default: json); label requires
                        --field.
  --since SINCE         Relative duration such as 15m.
  --start START         RFC 3339 range start.
  --end END             RFC 3339 range end (default: now).
  --limit LIMIT         Maximum candidates per request (1-5000; default: 100,
                        scan: 1000).
  --direction {backward,forward}
  --output {human,raw,jsonl}
  --service-field SERVICE_FIELD
                        Returned service label (default: app).
  --field NAME          Literal JSON key or label name; repeat to match any
                        selected field.
  --path POINTER        JSON Pointer to nested object members; JSON source
                        only.
  --timeout TIMEOUT
  --max-http-attempts MAX_HTTP_ATTEMPTS
                        HTTP attempt ceiling including retries; explicit cap
                        emits stderr accounting.
  --scan                Use the shared bounded adaptive scan engine.
  --max-elapsed-seconds MAX_ELAPSED_SECONDS
                        Scan elapsed budget (default: 300).
  --max-records MAX_RECORDS
                        Scan retained candidate budget (default: 10000).
  --work-dir WORK_DIR   Persist trace scan candidates and progress in this
                        directory.
  --report REPORT       Write trace completeness JSON to this file.
