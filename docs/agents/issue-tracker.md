# Issue tracker: GitHub

Issues and specs for this repository live in the GitHub Issues tracker for
`Nza6920/grafana-loki-query-cli`. Use the `gh` CLI for all operations.

## Conventions

- Create, read, list, comment on, label, and close issues with `gh issue`.
- When a skill says to publish to the issue tracker, create a GitHub Issue.
- When a skill says to fetch a ticket, read the GitHub Issue and its comments.
- Pull requests are not a triage request surface.
- Apply labels using the vocabulary in `docs/agents/triage-labels.md`.
